# Контракт анимации для рендера

Рендерер (`scripts/render.mjs`) покадрово ставит время `t` (миллисекунды от 0) и делает скриншот.
Анимация должна быть **функцией времени**. Поддерживаются два способа (можно сочетать):

1. **CSS-анимации / Web Animations API** — рендерер ставит `currentTime` у всех
   `document.getAnimations()` и паузит их. Используй `animation-fill-mode: both`
   и задержки (`animation-delay`) для раскладки по таймлайну. Бесконечные циклы допустимы.
2. **Хук `window.__setTime(ms)`** — для canvas/SVG/JS-анимаций. Функция должна полностью
   перерисовать состояние для момента `ms` (без накопления состояния между вызовами).

## Запрещено
- `setTimeout`/`setInterval`/`requestAnimationFrame` как источник времени, `Date.now()`, `Math.random()` без seed
  (рендер должен быть повторяемым).
- Внешние ресурсы по сети (шрифты, картинки, скрипты) — только inline / data-URI / системные шрифты.
- Скролл страницы: кадр = viewport заданного размера, `overflow: hidden`.

## Рекомендации
- Размеры в `vw`/`vh`/`%` или фиксированные под целевой формат.
- Easing: `cubic-bezier(.2,.8,.2,1)` для появления, `ease-in` для ухода.
- Первые 0.3–0.5 с — «крючок», последние 1–1.5 с — финальный кадр с призывом/логотипом, удерживаемый.
