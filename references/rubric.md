# Рубрика оценки вариантов

Оценка 1–5 по каждому критерию, смотря на кадры (contact sheet + отдельные кадры).

| Критерий | Что проверять |
|---|---|
| Соответствие брифу | Тема, тон, текст, формат |
| Читаемость | Контраст, размер текста, текст не обрезан и не выходит за кадр |
| Иерархия | Понятно, что главное; взгляд ведётся по порядку |
| Композиция и баланс | Отступы, выравнивание, пустое пространство, нет «слипания» |
| Ритм и динамика | Есть крючок, развитие, финал; смены не слишком частые/редкие |
| Плавность | В соседних кадрах нет скачков, элементы не «телепортируются» |
| Цельность стиля | Палитра, шрифты, формы единообразны |
| Финальный кадр | Законченный, удерживается, содержит главный посыл |

Для каждого варианта фиксируй: **сумма**, **сильнейшая сторона**, **слабейшая сторона**.
Победитель — максимальная сумма; при равенстве — выше «Соответствие брифу» и «Читаемость».
Затем перечисли заимствования из проигравших вариантов — только конкретные, проверяемые на кадрах.
