# Свой бренд-кит

Положи сюда официальные файлы логотипов — они **всегда** выигрывают у автопоиска и работают без сети.

Имя файла = нормализованное название бренда (строчные буквы и цифры, без пробелов и знаков):

| Бренд в `P.logo('…')` | Файл |
|---|---|
| `Duolingo` | `duolingo.svg` (или `.png`, `.webp`, `.jpg`) |
| `Visual Studio Code` | `visualstudiocode.svg` |
| `Яндекс` | `яндекс.svg` |

SVG лучше растра: масштабируется без потери качества. Для однотонных SVG `P.logo(name, size, {color})` не перекрашивает (перекраска только у simple-icons) — положи уже нужную версию (светлую/тёмную) под разными именами, например `duolingo-white.svg` → `P.logo('duolingo-white')`.
